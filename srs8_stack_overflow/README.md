# СРС № 8: Ограничения стека в микроконтроллерах (Arduino Uno / ATmega328P)

Практическая работа по исследованию работы оперативной памяти (SRAM) и переполнения стека (stack overflow) при использовании рекурсивных функций в среде симуляции Wokwi.

## О проекте

В данной работе на примере платы Arduino Uno (объём SRAM 2 КБ/2048 байт) показано:
1. Как глубокая рекурсия и локальные массивы быстро забивают оперативную память микроконтроллера.
2. Какие реальные сбои возникают при переполнении стека (зависания, искажение вывода в Serial Monitor).
3. Как заменить опасную рекурсию на безопасный и предсказуемый цикл.

## Структура репозитория

- `crash.ino` — демонстрация переполнения стека при глубокой рекурсии.
- `safe.ino` — безопасная итеративная версия программы (через обычный цикл `for`/`while`).
- `memory_hog.ino` — эксперимент по пошаговому заполнению памяти локальными массивами (уровни от 0 до 4).
- `REPORT.md` — полный отчёт с описанием хода работы, таблицей замеров и выводами.
- `screenshots/` — скриншоты результатов симуляции из Wokwi (включая `memory_hog_result.png`).
